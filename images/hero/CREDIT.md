# Image credit

`atlas-event.jpg` and `atlas-event-transverse.jpg` are derived from the ATLAS
candidate event display

> pp → H(→bb) + W(→µν), Run 338712, Event 335908183, recorded 2017-10-19
> **ATLAS Experiment © 2017 CERN**

Both files are resized/cropped versions of the original PNG supplied by the PI.
The credit line must appear wherever the image is displayed — it is already in
the `<figcaption>` on every page that uses it.

**Before going live:** confirm the licence on the ATLAS public-results page for
this event display. ATLAS public images are normally CC-BY-4.0, which this use
satisfies, but the specific record should be checked.

The logo mark in `images/logo/` is *traced* from the transverse view of this
same event: the 23 track angles and the muon direction were measured from the
pixels of the official display, not drawn freehand. See the comment at the top
of `images/logo/rodem-mark.svg`.
