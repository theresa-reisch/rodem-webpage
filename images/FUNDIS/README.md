# FUNDIS kickoff 2026 photographs

Talk photographs from the kickoff of Foundation Models for Scientific Discovery
(FUNDIS) at the Villa Boninchi, October 2026, referenced from `photos:` in the
FUNDIS news item (`assets/js/content.js`) and shown at the bottom of that item on
`news.html`. The group photograph is `images/events/boninchi-2026-fundis.jpg`,
shared with the workshop entry on `output.html#workshops`.

Web-sized like the other photographs: 1400px on the long edge, JPEG quality 82,
all 4:3. See `images/events/README.md` for the recipe. The phone originals
(`images/IMG_*.jpg`) are not kept in the repository.

Every photograph needs an `alt:` line saying what it shows, and anyone
recognisable in one should be happy to be on a public page.
