# EuCAIFCon 2026 photographs

Talk photographs from EuCAIFCon 2026 in Heidelberg, referenced from `photos:`
in the EuCAIF news item (`assets/js/content.js`) and shown at the bottom of that
item on `news.html`.

Web-sized like the workshop photographs: 1400px on the long edge, JPEG quality
82, around 150 kB each. See `images/events/README.md` for the recipe. The phone
originals (`IMG_*.jpg`, `AIPHY.jpg`) sit here untracked so the recipe can be
re-run; git ignores them.

Every photograph needs an `alt:` line saying what it shows, and anyone
recognisable in one should be happy to be on a public page.
