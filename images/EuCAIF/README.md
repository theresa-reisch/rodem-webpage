# EuCAIFCon 2026 photographs

Photographs from the EuCAIFCon 2026 week in Heidelberg — the talks, and the
AIPHY network meeting held in the same week. Each is referenced from `photos:`
in its news item (`assets/js/content.js`) and shown at the bottom of that item
on `news.html`.

Web-sized like the workshop photographs: 1400px on the long edge, JPEG quality
82, around 150 kB each. See `images/events/README.md` for the recipe. A group
photograph is cropped before resizing, so it does not push the rest of the news
item off the screen — `aiphy-network.jpg` drops the empty facade above the group
and lands near 1.6:1.

The phone originals (`IMG_*.jpg`, `AIPHY.jpg`) sit here untracked so the recipe
can be re-run; git ignores them.

Every photograph needs an `alt:` line saying what it shows, and anyone
recognisable in one should be happy to be on a public page.
