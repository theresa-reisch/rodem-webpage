# HMBS + Exotics workshop 2026 photographs

Photographs from the ATLAS HMBS + Exotics workshop in Clermont-Ferrand
(26–30 October 2026), taken by Nicolas Cartalade, referenced from `photos:` in
the news item (`assets/js/content.js`) and shown at the bottom of that item on
`news.html`. Each entry carries a `credit:` line naming the photographer.

Web-sized like the other photographs: 1400px on the long edge, JPEG quality 82,
all 4:3. See `images/events/README.md` for the recipe. The camera originals
(`images/IMG_*.JPG`) are not kept in the repository.

Every photograph needs an `alt:` line saying what it shows, and anyone
recognisable in one should be happy to be on a public page.
