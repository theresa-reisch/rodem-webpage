# ITk photographs

The pictures under the ATLAS Inner Tracker block on `research.html#itk`,
referenced from `photos:` in `DETECTOR` (`assets/js/content.js`). They are shown
side by side, so keep them to a pair and to the same shape — both are 4:3.

Web-sized exactly like the workshop photographs: 1400px on the long edge, JPEG
quality 82, around 220 kB each. See `images/events/README.md` for the recipe.
The clean-room originals are not in this repository.

Every photograph needs an `alt:` line saying what it shows, and anyone
recognisable in one should be happy to be on a public page.
